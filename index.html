Your form data gets redacted before it ever leaves the page.

PrivacyPilot is a local browser agent: it scans pages for sensitive fields, masks them on sight, and keeps an encrypted vault on your own machine. Nothing is sent to a server you don't control — there isn't one.

What it actually does

Three local operations, no account, no cloud dependency.

01 — Scan

Detect sensitive fields

Reads page text and form fields for emails, phone numbers, IDs, card numbers, and anything named like a password or token.

02 — Redact & vault

Encrypt before storing

Matched values are masked in view. Anything saved is encrypted with AES-GCM in the extension before it touches disk.

03 — Fill

Restore on demand

Decrypts the local vault record and refills a form — sensitive and non-sensitive fields alike — only on this device.

Run it

This is a local tool — install it in your own Chrome, not on a hosted URL.

  1. Download and unzip the project folder.
  2. Start the backend: run backend/run_backend.sh (or .bat on Windows).
  3. In Chrome, open chrome://extensions and turn on Developer mode.
  4. Click Load unpacked and select the extension folder.
  5. Reload the page you want to protect, then open PrivacyPilot from the toolbar.

Limitation, stated plainly

This is a prototype, not a certified password manager. AES-GCM protects the stored vault record, but the decryption key is held by the extension itself — so any copy of this same extension, installed anywhere, can decrypt it. Treat it as a demo of the redaction and local-vault pattern, not production key management.
